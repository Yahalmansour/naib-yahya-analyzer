# نائب | المحلل والمدقق الشامل

تطبيق ويب عربي باتجاه RTL لإدارة فحص أولي للعقود، الحركات المالية، والملفات، وأمن الموقع. يعمل على Netlify: الواجهة HTML/CSS/JavaScript ثابتة، والـAPI دالة Netlify Function واحدة على المسار `/api/*`، والبيانات في Netlify Database (Postgres مُدار عبر Drizzle ORM)، والملفات المرفوعة في Netlify Blobs.

> **تنبيه قانوني:** فحص العقود يعتمد على وجود كلمات مفتاحية وبنود ظاهرة في النص، ولا يفسّر النص ولا يؤكد امتثاله للأنظمة السعودية. النتيجة ليست استشارة قانونية؛ اعرض العقود على محامٍ مرخص. لا تُدخل بيانات حساسة إلى خادم غير موثوق.

## البنية

| المسار | المحتوى |
| --- | --- |
| `public/` | الواجهة (تُنسخ إلى `dist/` أثناء البناء) |
| `netlify/functions/api.mts` | دالة الـAPI لجميع مسارات `/api/*` |
| `netlify/functions/permit-alerts.mts` | دالة مجدولة كل ساعة لتنبيهات واتساب للتصاريح |
| `server/` | منطق الـAPI والتحقق والمصادقة والتنبيهات |
| `db/schema.ts` | مخطط قاعدة البيانات (Drizzle) |
| `netlify/database/migrations/` | ملفات الترحيل؛ تطبقها Netlify تلقائياً عند النشر |
| `scripts/build.mjs` | خطوة البناء وتفعيل الحماية من اختلاف الإصدارات (Skew Protection) |

## التشغيل والتطوير

- Node.js 22 أو أحدث، وNetlify CLI.

```sh
npm install
netlify dev   # الواجهة والدوال وقاعدة البيانات وBlobs محلياً على http://localhost:8888
npm test      # اختبارات تكاملية على Postgres داخل الذاكرة (PGlite) دون أي خدمة خارجية
```

عند تعديل `db/schema.ts` أنشئ ترحيلاً جديداً بالأمر `npx drizzle-kit generate --name <وصف_التغيير>`. لا تعدّل ملف ترحيل طُبّق مسبقاً، ولا تطبّق الترحيلات يدوياً: Netlify تطبقها قبل نشر الإصدار، وتنشئ لكل معاينة نشر (Deploy Preview) فرعاً معزولاً من قاعدة البيانات.

## متغيرات البيئة

اضبطها من لوحة Netlify (Project configuration ← Environment variables) مع نطاق Functions:

- `INITIAL_ADMIN_SETUP_KEY` (مطلوب لإنشاء الحساب الأول): قيمة عشوائية بطول 32 بايت على الأقل، مثل ناتج `node -e "console.log(require('node:crypto').randomBytes(48).toString('hex'))"`. يسلمها مدير المنصة للمسؤول الأول بأمان.
- `TOKEN_SECRET` (اختياري): مفتاح توقيع رموز الدخول، 32 بايت على الأقل. إن لم يُضبط تولّد المنصة مفتاحاً عشوائياً مرة واحدة وتحفظه في قاعدة البيانات لتشترك فيه جميع نسخ الدالة. تغييره يُنهي جميع الجلسات الحالية.
- `WHATSAPP_ACCESS_TOKEN`، `WHATSAPP_PHONE_NUMBER_ID`، `WHATSAPP_ALERT_RECIPIENT`، `WHATSAPP_TEMPLATE_NAME`، `WHATSAPP_TEMPLATE_LANGUAGE`، `WHATSAPP_API_VERSION` (اختيارية): لتفعيل تنبيهات واتساب. اضبطها كلها أو اتركها كلها فارغة.

أول حساب يُنشأ من شاشة الدخول يصبح مسؤول النظام، ويستخدم اسماً كاملاً ومعرف دخول خاصاً به وكلمة مرور لا تقل عن 12 حرفاً ورمز `INITIAL_ADMIN_SETUP_KEY`. لا يحتاج المالك إلى ربط حسابه بهوية وطنية. لا يمكن إكمال التهيئة دون الرمز. بعد إنشاء المسؤول، يتوقف التسجيل الأولي ولا يستطيع دخول المنصة إلا أصحاب الحسابات التي ينشئها المسؤول؛ لا يوجد تسجيل عام أو كلمة مرور افتراضية. يدخل الموظف باسمه الكامل ورقم هويته وكلمة مروره. يمكن للمالك ضبط أو تغيير معرف دخوله من قسم المستخدمين، ولا يظهر المعرف ضمن بيانات الحساب أو واجهات الموظفين. سجلات الإجراءات اليومية والتصاريح والصور تتطلب تسجيل الدخول وتحفظ اسم المستخدم الذي أضافها.

## النشر والأمان

- **الحماية من اختلاف الإصدارات (Skew Protection):** خطوة البناء تضمّن رمز الإصدار الذي توفره Netlify (`NETLIFY_SKEW_PROTECTION_TOKEN`) في الصفحة، وترسله الواجهة مع كل طلب API في الترويسة `x-skew-token`، وتُثبَّت ملفات `app.js` و`styles.css` بالمعامل `?skew=`. يكتب البناء الملف `.netlify/v1/skew-protection.json` ليوجّه Netlify هذه الطلبات إلى الإصدار نفسه الذي فُتحت منه الصفحة، فلا تتعطل الجلسات المفتوحة عند نشر إصدار جديد. تتحدث الواجهة إلى أحدث إصدار عند إعادة تحميل الصفحة. تعمل الحماية على الإصدار المنشور (Production) فقط، وتتجاوزها Netlify إذا كانت حماية كلمة المرور مفعّلة على جميع الإصدارات. لأن قاعدة البيانات مشتركة بين الإصدارات، اجعل تغييرات المخطط متوافقة مع الإصدار السابق (أضف أعمدة وجداول أولاً، واحذف القديم في نشر لاحق).
- تُحدّ طلبات الـAPI إلى 300 طلب في الدقيقة لكل عنوان IP عبر حدود المعدل في Netlify، ومحاولات الدخول أو الإعداد الفاشلة إلى 10 محاولات خلال 15 دقيقة لكل عنوان IP؛ تُحفظ المحاولات في قاعدة البيانات لتسري على جميع نسخ الدالة.
- تُخزّن كلمات المرور على شكل تجزئة scrypt. تضيف الواجهة والـAPI ترويسات أمان (CSP وHSTS وغيرها)، واستجابات الـAPI لا تُخزَّن مؤقتاً.
- **حدود الملفات:** تقبل دوال Netlify طلبات حتى 6 ميجابايت، لذا الحد الأقصى لأي ملف أو صورة مرفوعة 4 ميجابايت.
- **تنبيهات واتساب:** تفحص الدالة المجدولة التصاريح كل ساعة على الإصدار المنشور، وترسل إشعاراً واحداً عند دخول التصريح فترة الثلاثين يوماً وآخر عند انتهائه. تُحجز كل رسالة قبل إرسالها لمنع التكرار، والإرسال الفاشل يعاد بعد نحو ساعة. أنشئ حساب WhatsApp Business Cloud API وخذ موافقة المستلم وأنشئ قالباً معتمداً بأربعة متغيرات نصية بالترتيب: رقم التصريح، اللوحة، تاريخ الانتهاء، وحالة التصريح. لا تضع رقم المستلم أو رمز الوصول في Git.
- رقم الهوية بيانات شخصية؛ قيّد الوصول إلى المشروع على Netlify وإلى قاعدة البيانات.

## الوظائف

- **المستندات:** ألصق نص العقد لفحص مؤشرات الأطراف، والالتزامات، والمقابل، والمدة، والإنهاء، والنزاعات، والتوقيع. تُحفظ النتائج مع مؤشر اكتمال تقريبي. يمكن تنزيل تقرير JSON أو طباعته/حفظه PDF من المتصفح.
- **المحاسبة:** سجّل الإيرادات والمصروفات والمشتريات بعملة وتاريخ، وابحث في الحركات، واحذفها. ملخص السنة والرسم الشهري يعرضان SAR، ويمكن تصدير السجل CSV المتوافق مع برامج الجداول.
- **الوسائط:** رفع PDF وDOC/DOCX وXLS/XLSX وJPG وPNG حتى 4 ميجابايت، وتصنيفها وتنزيلها وحذفها. معاينة الصور متاحة داخل التطبيق.
- **أمن الموقع:** سجل دخول وخروج الزوار مع بيانات كل شخص وعددهم والبوابة والغرض، وصورة اختيارية للمركبة واللوحة، وتقارير أمنية مصورة، وإدارة تصاريح المركبات مع صورة للتصريح وتنبيهات داخل المنصة، وتنبيهات واتساب اختيارية لمستلم واحد عند ضبط حساب Cloud API. لكل مركبة رمز ثابت يُنشأ تلقائياً، ويمكن الاستعلام برقم اللوحة أو الرمز. يدعم الإملاء الصوتي العربي في المتصفحات التي توفره؛ التفريغ مسودة قابلة للتحرير والمراجعة ولا يضمن دقة كاملة. يمكن استخدام إملاء لوحة مفاتيح الآيفون كبديل.
- **طلبات الفريق:** يرسل الموظفون رسالة بسيطة لاقتراح ميزة أو تحسين أداء أو متطلب أمني أو الإبلاغ عن مشكلة. يراجع المسؤول الطلب ويحدّث حالته؛ لا تُطبّق الرسائل أو "التعلّم" تلقائياً.
- **المستخدمون والتدقيق:** الحساب الأول مسؤول، ويمكن للمسؤول إنشاء مستخدمين بصلاحية مسؤول أو مستخدم. العمليات المهمة تسجل في سجل تدقيق.
- **الواجهة:** لوحة عربية متجاوبة مع الهاتف، مؤشرات مالية، ورسم شهري مبني دون خدمة خارجية.

هذا إصدار تأسيسي لا يتضمن استخراج نص تلقائياً من ملفات PDF/Word/Excel أو تحليلاً بالذكاء الاصطناعي، ولا يطبّق قواعد امتثال قانونية معتمدة، ولا يوفر بعد دورة فواتير كاملة أو قيوداً محاسبية مزدوجة. نص المستند للتحليل يُدخل يدوياً؛ أما رفع الملفات فهو للتخزين والمعاينة والتنزيل.

## API

جميع المسارات باستثناء فحص الصحة وحالة إعداد الحساب تتطلب رمز `Bearer` يعاد من تسجيل الدخول أو إعداد الحساب. الرموز تنتهي بعد 12 ساعة.

| الطريقة والمسار | الغرض |
| --- | --- |
| `GET /api/health` | فحص الخدمة |
| `GET /api/auth/status` | معرفة ما إذا أُنشئ الحساب الأول |
| `POST /api/auth/register` | إنشاء حساب المالك الأول فقط (`username` الاسم الكامل, `ownerLoginId`, `password`, `setupKey`) |
| `POST /api/auth/login`، `GET /api/auth/me` | تسجيل الدخول بمعرف المالك أو رقم هوية الموظف مع كلمة المرور وبيانات الحساب |
| `GET/PUT /api/organization` | عرض اسم الجهة وموقع العمل للمستخدم المسجل؛ التعديل للمسؤول فقط (`organizationName`, `workLocation`). القيم الأولية: المربع الجديد، شمال الرياض |
| `GET/POST /api/users`، `PATCH /api/users/:id/identity`, `PATCH /api/users/:id/owner-login` | عرض المستخدمين وإضافتهم وربط هوية الموظف أو ضبط معرف دخول المالك (للمسؤول فقط) |
| `GET /api/documents`، `POST /api/documents/analyze` | عرض المستندات وفحص نص (`title`, `content`) |
| `GET/DELETE /api/documents/:id` | تقرير JSON أو حذف مستند |
| `GET/POST /api/accounting/transactions` | عرض الحركات أو إضافة حركة (`kind`, `description`, `amount`, `date`, `currency`) |
| `DELETE /api/accounting/transactions/:id` | حذف حركة |
| `GET /api/accounting/summary?year=2026` | إجماليات السنة والتوزيع الشهري |
| `GET /api/accounting/export.csv` | تصدير الحركات |
| `GET /api/security/summary` | عدد الأشخاص داخل الموقع والتصاريح المنتهية أو القريبة من الانتهاء |
| `GET/POST /api/security/access`، `POST /api/security/access/:id/exit` | عرض سجل الدخول والخروج، تسجيل دخول أشخاص (`people`, `organization`, `purpose`, `gate`, `vehiclePlate`) وتسجيل المغادرة |
| `GET /api/security/vehicles?plate=...` | الاستعلام برقم لوحة المركبة أو رمزها وعرض الرمز الثابت والتصاريح وسجل الزيارات |
| `GET/POST /api/security/permits` | عرض التصاريح أو إضافة تصريح مركبة كـ`multipart/form-data`؛ يتضمن `permitNumber`, `vehiclePlate`, بيانات السائق، `validFrom`, `validUntil` وصورة `permitPhoto` بصيغة JPG/PNG حتى 4 ميجابايت |
| `GET/POST /api/security/reports` | عرض التقارير الأمنية أو إضافة تقرير (`title`, `category`, `location`, `details`) مع صورة `reportPhoto` بصيغة JPG/PNG حتى 4 ميجابايت |
| `GET/POST /api/security/procedures` | عرض سجل الإجراءات اليومية أو إضافة إجراء باسم المستخدم الحالي؛ صورة `procedurePhoto` اختيارية بصيغة JPG/PNG حتى 4 ميجابايت |
| `GET/POST /api/feature-requests`، `PATCH /api/feature-requests/:id` | الموظف يرسل طلباً ويتابع طلباته؛ المسؤول يراجع جميع الطلبات ويغيّر حالتها |
| `GET/POST /api/media` | عرض الملفات أو رفع `multipart/form-data` باسم الحقل `file` |
| `GET /api/media/:id`، `GET /api/media/:id/preview`، `DELETE /api/media/:id` | تنزيل أو معاينة صورة أو حذف ملف |
| `GET /api/audit` | أحدث 100 عملية مسجلة |

أنواع الحركة هي `income` و`expense` و`purchase`. أرسل رمز الدخول في ترويسة التفويض القياسية لكل طلب محمي. صلاحيات المستخدمين العاديين تتيح وظائف المستندات والمحاسبة والوسائط، بينما إدارة المستخدمين مقتصرة على المسؤول.

## التخزين

- البيانات: Netlify Database (Postgres مُدار). تُدار النسخ الاحتياطية والتوفر من المنصة، ولكل معاينة نشر فرع مستقل من البيانات.
- الملفات المرفوعة: مخزن Netlify Blobs باسم `media`، وبياناتها الوصفية في جدول `media`.
- البيانات من الإصدار السابق (SQLite و`data/uploads/`) لا تُنقل تلقائياً؛ انقلها بسكربت مخصص إن احتجت إليها. تجزئات كلمات المرور متوافقة ويمكن نقلها كما هي.

لا تحفظ الأسرار في Git.
